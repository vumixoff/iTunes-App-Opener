# 📱iTunes-App-Opener 

Это лёгкая утилита, которая открывает страницы приложений в iTunes по их App Store ID. Позволяет быстро переходить к нужному приложению без ручного поиска в App Store, используя протокол itmss:// и встроенный AppStore, и которая дополняет поиск для iTunes 12.6.5.3.

                          
✨ Возможности:                                                                         
• 🔍 Открытие приложений по App Store ID — мгновенный переход на страницу приложения                                                                  
• 🏪 AppStore, встроенный в программу — не нужно переключаться между окнами               
• 🌐 Режим прокси — работа через прокси-сервер                   
• 🔗 Использование протокола itmss:// — нативная интеграция с iTunes                  
• 🪶 Минималистичный код без зависимостей — не требует установки дополнительных библиотек                        
• 🪟 Совместимость с Windows                        

🖥️ Требования:               
• Windows (любая актуальная версия)                              
• iTunes 12.6.5.3 (или совместимая версия)                            
• Установленный протокол itmss:// (регистрируется автоматически при установке iTunes)

⚠️ Примечания:                            
• Убедитесь, что iTunes установлен и протокол itmss:// зарегистрирован в системе                            
• При использовании прокси-режима проверьте корректность настроек прокси               
• Программа не требует прав администратора для базовой работы
